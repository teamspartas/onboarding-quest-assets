# 온보딩 퀘스트 이미지 자산

Slack 온보딩 퀘스트 카드가 사용하는 공개 이미지 저장소입니다.

## URL 규칙

- 카드별 경로: `/cards/<card-id>/<asset-name>-v<version>.<ext>`
- 기존 파일을 덮어쓰지 않고 수정 시 버전을 올립니다.
- Google Sheet에는 GitHub Pages의 절대 HTTPS URL을 입력합니다.
